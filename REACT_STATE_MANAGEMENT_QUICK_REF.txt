# React State Management - Quick Reference

## Problem
UI doesn't update after CRUD operations without manual page refresh.

## Solution: Two Options

### Option 1: Re-fetch (Simplest)
```javascript
const handleSaveEvent = async (formData) => {
  await apiPost('/events', formData);
  await fetchEvents(); // ← Re-fetch everything
};
```
✅ Simple, accurate
❌ Slight delay (~500ms)

### Option 2: Local State (Fastest)
```javascript
const handleSaveEvent = async (formData) => {
  const response = await apiPost('/events', formData);
  setEvents(prev => [...prev, response.data]); // ← Update immediately
};
```
✅ Instant, fast
❌ More complex

---

## Which Should I Use?

```
Is data accuracy CRITICAL?
  ↓ YES → Use Option 1 (Re-fetch)
  ↓ NO → Is speed CRITICAL?
           ↓ YES → Use Option 2 (Local State)
           ↓ NO → Use Option 1 (safer)
```

## Verify Backend Actually Updated

### Problem Example
```
1. Add Event → Shows success
2. Event appears in UI
3. Refresh page → Event is gone
```

### Solution
Add this to your component:

```javascript
import { verifyCrudOperation, logVerificationResult } from '../../utils/verificationUtils';

const handleSaveEvent = async (formData) => {
  try {
    const response = await apiPost('/events', formData);
    
    // Verify database actually updated
    const verification = await verifyCrudOperation({
      operation: 'create',
      apiResponse: response,
      eventId: response.data?.id,
    });
    
    logVerificationResult(verification);
    
    if (verification.errors.length > 0) {
      throw new Error(verification.errors[0]);
    }
    
    // Update UI
    setEvents(prev => [...prev, response.data]);
  } catch (err) {
    console.error(err);
  }
};
```

## Common Issues

### Issue 1: Add shows success but disappears on refresh
```
❌ Backend not actually saving to database
✅ Check: 
   - Is INSERT query executing? (Add logging to PHP)
   - Is database connection working?
   - Are there any SQL errors? (Check logs)
   - Did lastInsertId() return a valid ID?
```

### Issue 2: Changes show but different values appear
```
❌ Server is sanitizing/transforming data
✅ Check:
   - Are submitted and returned values the same?
   - Is backend sanitization changing input? (trim, htmlspecialchars)
   - Is type casting rounding numbers?
   - Are default values overriding submitted data?
```

### Issue 3: Delete shows success but event still exists
```
❌ DELETE query not executing
✅ Check:
   - Add error logs in PHP delete function
   - Verify WHERE clause has correct ID
   - Check if transaction is committed
   - Run SELECT after DELETE to verify
```

## Debugging Steps

1. **Open DevTools** (F12)
2. **Check Console tab** for errors
3. **Check Network tab**:
   - Does API return data.id?
   - Is HTTP status 200?
4. **Check phpMyAdmin** (http://localhost:8080):
   - Is event actually in database?
5. **Check PHP logs**:
   ```bash
   docker-compose logs php | tail -50
   ```

## Copy-Paste Snippets

### Option 1: Simple Create
```javascript
const handleSaveEvent = async (formData) => {
  try {
    await apiPost('/events', formData);
    await fetchEvents();
    setShowAddModal(false);
  } catch (err) {
    setNotification({ type: 'error', message: err.message });
  }
};
```

### Option 1: Simple Delete
```javascript
const handleConfirmDelete = async () => {
  try {
    await apiDelete(`/events/${deleteConfirm.id}`);
    await fetchEvents();
    setDeleteConfirm(null);
  } catch (err) {
    setNotification({ type: 'error', message: err.message });
  }
};
```

### Option 2: Create with Local State
```javascript
const handleSaveEvent = async (formData) => {
  try {
    const response = await apiPost('/events', formData);
    setEvents(prev => [...prev, response.data]);
    setShowAddModal(false);
  } catch (err) {
    await fetchEvents(); // Fallback to re-fetch on error
    setNotification({ type: 'error', message: err.message });
  }
};
```

### Option 2: Delete with Rollback
```javascript
const handleConfirmDelete = async () => {
  const eventToDelete = deleteConfirm;
  
  try {
    setEvents(prev => prev.filter(e => e.id !== eventToDelete.id));
    
    try {
      await apiDelete(`/events/${eventToDelete.id}`);
    } catch (err) {
      setEvents(prev => [...prev, eventToDelete]); // Rollback
      throw err;
    }
  } catch (err) {
    setNotification({ type: 'error', message: err.message });
  } finally {
    setDeleteConfirm(null);
  }
};
```
